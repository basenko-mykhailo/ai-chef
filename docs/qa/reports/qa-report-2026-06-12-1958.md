## Recommendations

- **Fix TC-004 step 2** — change the `Рецепти` expected href from `/recipes` to `/recipes/create` (and add a note, as was done for TC-006 step 3). This is a test-data correction, not a code change.
- **Flash visibility timing** — the "coming soon" flash auto-hides after 5s (Alpine `x-show` + `setTimeout`). It rendered correctly, but future timed-flash cases should assert against the DOM element rather than the rendered (visible) accessibility tree, since the banner may be hidden by the time a snapshot runs. Consider raising the auto-hide to ~8s or adding a manual dismiss for accessibility.
- **Untested areas (for future cases, deferred to later tickets):** the real generation flow (3.8 — `RecipeGenerationJob` dispatch, spinner/polling), recipe-card rendering (3.10), generation error handling (3.11), and the actual 10/hour throttle enforcement (3.12 — only the static hint is present today). The server-side guard for empty-pantry submission (the button is disabled client-side only in 3.7) should get a negative case once 3.8 adds the server check.
- **Members default-all semantics** — TC-008 confirms client-side default-checked + toggle; once 3.8 consumes `members[]`, add a case asserting the submitted set matches the checked boxes.
